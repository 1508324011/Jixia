# Code of Conduct

Jixia is committed to a respectful, constructive, and inclusive collaboration environment.

## Expected Behavior

- be respectful in issues, discussions, and pull requests
- focus criticism on ideas and implementation details, not people
- assume good intent while still being precise and rigorous
- keep technical discussions grounded in evidence and repository context

## Unacceptable Behavior

- harassment, personal attacks, or discrimination
- deliberate disruption of project discussions or reviews
- publishing private information without permission
- pressuring maintainers to merge changes that violate project rules

## Enforcement

Project maintainers may remove, edit, or reject contributions and discussions that
conflict with this code of conduct or the repository engineering charter.
